# MySatKit-Ground-Station

📻 **MySat Ground Station module** included in the MySat SPACE Kits.  
This is a radio transceiver based on the HC-12 module.

No special code or software is required for work, except for the one used in the [Main Guide](https://docs.google.com/document/d/146EPTvLMzydpwUMsbJWAC3gcRO6yPDe3p8kIpxRUwU4/edit?tab=t.0) (Arduino IDE, etc.).
